OFFHAND COMPANION
=================

Version: {{VERSION}}
Offhand.exe SHA-256: {{EXE_SHA256}}

INSTALLATION
------------
1. Extract all files from Offhand-Companion.zip to a folder you control.
2. Start Offhand.exe before launching World of Warcraft.
3. Review the selected displays and use Identify Displays before enabling
   automatic spanning.
4. Click Span WoW Now. If WoW already reached the character UI, type /reload.
5. In WoW, open /oh and complete the setup wizard. On Forever and Retail,
   press Create Mainhand HUD Layout on the final step outside combat with
   Edit Mode closed, then reload when prompted.

No installer is required. Offhand Companion uses the .NET Framework included
with supported Windows installations. Preferences are stored under
%LOCALAPPDATA%\Offhand.

SECURITY AND SOURCE
-------------------
Download Offhand only from the official GitHub releases page:
https://github.com/N4UX-GIT/Offhand-DualMonitor/releases

Verify Offhand.exe against the SHA-256 value above and the separately published
checksums-sha256.txt release asset. Never disable security software to install
or run Offhand. Report unexpected detections through the project issue tracker.

The complete source, build instructions, security documentation, and release
history are available in the public repository:
https://github.com/N4UX-GIT/Offhand-DualMonitor
