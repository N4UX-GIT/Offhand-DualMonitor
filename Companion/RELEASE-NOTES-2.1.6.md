# Offhand Companion 2.1.6

Submitted to Microsoft Store as Submission 7 on 2026-11-10. Certification is pending; publication will begin automatically after approval.

- A cleaner dashboard with centered Setup and Advanced tabs. Everyday display controls stay in Setup; custom workspaces, profiles, Auto-span, diagnostics and the activity log are in Advanced.
- A skippable first-run tutorial highlights the controls and explains their use. Replay it from Help whenever needed. It does not change selections or apply a layout for you.
- Clear, prominent Span and Restore actions with balanced alignment and stable window sizing.
- Updated Offhand branding, website/Discord/CurseForge links, and detected addon version information in the header.
- New two-monitor custom plans start with the full Offhand monitor. Previously saved custom areas and profiles are preserved.
- An active custom layout stays visible in the Advanced tab label, with a clear option to return to the standard display layout.

Enable the Offhand addon, enter the game world and use Windowed mode. After applying a layout with Span WoW Now, reload the WoW UI. First-time users should complete `/offhand guide`, calibration and any Mainhand HUD layout/reload prompts.

The current 2.1.5 Pre-Release Beta 28 addon remains compatible. Store settings persistence and quiet Store-managed update detection are retained. No new addon installation or protocol change is required for this Companion UI update.
