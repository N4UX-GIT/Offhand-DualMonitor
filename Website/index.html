Set up Offhand

Install the addon, choose one way to place WoW, then finish the guide inside the game.

1

Install the Offhand addon

Install Offhand with CurseForge or WowUp for the WoW client you play. Check supported clients.

Get the Offhand addon

Open the AddOns list at character selection and enable Offhand. Enter the world and type /offhand guide to open setup.

Offhand missing after a ZIP install?

Open the client folder you actually launch. Extract the Offhand folder into Interface/AddOns. The main addon’s TOC files should sit directly inside Interface/AddOns/Offhand. A path like Offhand/Offhand/Offhand.toc is one folder too deep. Restart WoW and check the AddOns list again.

2

Choose one window-placement method

For most Windows setups, choose Companion. If you prefer PowerToys or want to place the window yourself, choose one of the alternatives.

Before you choose a setup method: Companion is optional. We’ve asked Blizzard for clarification and are awaiting a reply. Read our assessment of account risk or set up manually.

Companion

Recommended for Windows

Use both full monitors, or share your second monitor with Discord or a browser using a custom workspace.

Use Companion

FancyZones

Alternative using Microsoft PowerToys

Use a saved PowerToys zone when both monitors use the same Windows display scaling percentage. Companion is not needed for this method.

For Mac or setup without a desktop utility

Drag and resize WoW yourself. You may need to repeat that placement after launching the game.

Set up manually

3

Finish inside WoW

Once WoW covers the screens you chose, return to the open in-game guide. Follow its prompts to reload, confirm which screen holds your game, and finish setup.

After setup: optional customization

Start with the standard layout. You can explore custom workspaces, background images and additional settings later. These are not extra setup methods or required first-run steps.

Companion: start with standard layout

The Microsoft Store Companion is the recommended Windows tool for positioning WoW. Standard layout is already selected for a new setup. Choose your screens in Setup, then confirm the layout in the WoW guide.

Two full monitors need no custom editor. To keep desktop apps alongside your WoW panels, reserve part of the second screen.

Get from Microsoft Store Open Companion Setup

Optional: make the canvas yours

Choose a PNG, JPEG, or WebP image, preview fill and fit behavior, and download a ready-to-install Offhand_UserMedia package. After installation and a full client restart, enable it from Offhand's Appearance tab.

The image is processed in your browser. It is not uploaded, retained, or sent to Offhand. The generated package contains a texture and declarative metadata, with no Lua or executable program code. It remains separate from the CurseForge-managed addon so normal updates cannot replace your background.

Frequently Asked Questions

Direct answers to common questions about safety, compatibility, and setup.

How do I set World of Warcraft into Windowed mode?

In WoW's Graphics options, select Windowed and apply. Windowed (Fullscreen) is different. See the Windowed mode screen and continue to placement.

How should I place action bars, XP, stance, party, and raid frames?

Where supported, the calibration wizard finishes with Create Mainhand HUD Layout. Reload when prompted, then use Blizzard Edit Mode for personal adjustments. Follow the calibration instructions; the HUD reference covers later changes. Custom action-bar addons retain ownership of their frames.

Does spanning World of Warcraft stretch or distort the 3D camera?

No. Offhand uses native Blizzard viewport coordinate APIs to constrain 3D camera rendering strictly to your primary monitor's pixel bounds. Your camera aspect ratio and field of view remain native 1:1, completely eliminating horizontal fisheye distortion.

Is the desktop companion app required?

No. Microsoft PowerToys FancyZones and ordinary manual resizing are complete standalone setup paths. Offhand remembers and validates the resulting canvas without communicating with another application. The optional Companion provides exact topology, borderless geometry, automatic spanning, and active recovery, but it may be exited after applying the span. Its Forever recovery bridge is only a compatibility fallback when /offhand diag reports that normal persistence is stale.

Read the FancyZones and manual setup guide.

Can I use my own image on the Offhand canvas?

Yes. Offhand includes built-in support for packages created by the Background Studio. The studio converts PNG, JPEG, or WebP images locally in your browser and creates a separate, code-free Offhand_UserMedia addon folder. Your image is not uploaded. Install both folders side by side, then enable Use installed custom background from the in-game Appearance tab. Keeping the media folder separate also prevents CurseForge updates from replacing your personal background.

Does it work with different monitor sizes and vertical screens?

Yes. FancyZones and manual placement use the canvas you confirm during setup, including portrait, landscape, mixed-resolution, stacked, and ultrawide arrangements. The optional Companion additionally passes the exact Windows rectangles for the selected Mainhand and workspace displays, including negative coordinates and unequal alignment.

Can I use one 49-inch 32:9 screen, or a 32:9 Mainhand plus another monitor?

For one super-ultrawide, select only it in the Companion, enable Single-display 32:9 split, and choose which half contains the game. For a 32:9 game screen plus a separate workspace screen, leave split mode disabled, select both displays, and choose the 32:9 display as Mainhand (game).

What happens if my second monitor is disconnected?

Offhand rejects mismatched saved geometry and restores a safe full-window viewport. With FancyZones or manual placement, restore the intended window before reapplying the remembered canvas. The Companion also remembers displays by Windows identity, refuses to collapse a two-display profile onto the remaining screen, and can restore a bordered Mainhand window while active.

How do Offhand, Companion, and FancyZones relate to Blizzard's rules?

Blizzard makes account enforcement decisions. Read Blizzard rules, bans and account risk for the project’s current guidance and official sources. You can use manual placement with the addon alone.

Which versions of World of Warcraft are supported?

Offhand supports WoW Forever (1.60.x), Retail, Classic Era and Hardcore, and progression/Anniversary Classic clients. Forever has a distinct Mainline-style UI and therefore uses Blizzard Edit Mode for protected action bars and combat frames.

Why must Forever use Blizzard Edit Mode?

Forever protects action bars, unit frames, and other combat UI. Offhand can safely restore ordinary workspace panels such as the map, character frame, backpack, and chat, but protected frames must remain owned by Blizzard Edit Mode. The setup wizard therefore creates and selects a Mainhand-safe Blizzard layout through its final player-click action. Use Blizzard Edit Mode for personal fine-tuning, and use Recovery & Preview to rebuild or designate the layout later.
