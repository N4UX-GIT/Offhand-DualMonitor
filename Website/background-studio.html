SECURITY BY DESIGN

A code-free media package

The studio converts your image into a narrow, predictable addon package. It does not create or include executable program code.

Processed locally

Your image is decoded, resized, previewed, and packaged by your browser. It is not uploaded to Offhand, retained by the site, or embedded in analytics.

Four known files

The generated ZIP contains a TGA texture, declarative TOC metadata, a JSON recipe, and a plain-text README. It contains no Lua, EXE, DLL, installer, macro, or network code.

Strict package inspection

Update package reads the ZIP in memory without extracting or executing it. It accepts only known paths and rejects traversal paths, links, encryption, compression, unexpected files, oversized data, malformed headers, and failed CRC checks.

Generated package contents Offhand_UserMedia.toc BackgroundRecipe.json README.txt Textures/Background.tga
Do not install a media ZIP received from another person directly. Any addon folder can be modified after generation. Open the ZIP with Update package on this official studio page, review the preview, and generate a new code-free package before installing it. Older Studio packages containing Background.lua are accepted for this local conversion but are never carried into the replacement ZIP. Review the project’s complete security policy for reporting and verification guidance.
INSTALLATION

Install beside Offhand

1. Close WoW

A full client restart is the safe requirement for newly generated interface textures. Do not replace the package while WoW is running.

2. Extract the ZIP

Place Offhand_UserMedia beside Offhand inside the client’s Interface/AddOns directory. Avoid creating a nested duplicate folder.

3. Start and enable

Start WoW, verify Offhand User Media is enabled, then open /offhand, select Themes, and enable Use installed custom background. Offhand falls back to its normal theme if the package is unavailable.

IN-GAME SETTINGS

Enable and adjust your background in Offhand

The generated package supplies the image and its presentation settings. Offhand’s Themes page controls whether it is shown and lets you override its fit mode.

  1. Open OffhandType /offhand or /oh.
  2. Select ThemesScroll to 4. Background Studio.
  3. Check the package statusA usable package reports Ready with its image and texture dimensions.
  4. Enable the backgroundSelect Use installed custom background. Changes apply automatically.

Fill
Covers the complete Offhand background area. Cropping, focus, and zoom come from the Studio preview.
Fit
Shows the complete image without distortion and uses the selected matte colour around it.
Stretch
Fills the complete Offhand background area by stretching the image to its shape.

To change crop focus, zoom, opacity, darkening, or matte colour, update the package in this studio and fully restart WoW after replacing the folder.

Using CurseForge

Open your active World of Warcraft profile and use its Open Folder or Browse Folder action. The correct AddOns folder is the one that already contains Offhand.

Using Battle.net

Select the WoW version you play, open the options beside Play, and show the installation in Explorer. Open the matching game-version folder, then Interface and AddOns.

Common version folders _retail_\Interface\AddOns _classic_\Interface\AddOns _classic_era_\Interface\AddOns

Check before extracting: Offhand and Offhand_UserMedia must be side by side inside the same AddOns folder, not nested inside one another. Your drive and parent folders may differ if WoW was installed in a custom location.

Update or remove

Close WoW before replacing Offhand_UserMedia. To remove it, disable the custom background and delete only that folder. Normal CurseForge updates leave this user-owned package alone.

Expected folder structure

Keep both addon folders side by side inside Interface/AddOns.

Interface/AddOns/
├── Offhand/
└── Offhand_UserMedia/
