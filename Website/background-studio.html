INSTALLATION

Install beside Offhand

1. Close WoW

A full client restart is the safe requirement for newly generated interface textures. Do not replace the package while WoW is running.

2. Extract the ZIP

Place Offhand_UserMedia beside Offhand inside the client’s Interface/AddOns directory. Avoid creating a nested duplicate folder.

3. Start and enable

Start WoW, verify Offhand User Media is enabled, then select the custom background in /offhand. Offhand falls back to its normal theme if the package is unavailable.

? Can’t find your AddOns folder? Open the folder guide ▾

Using CurseForge

Open your active World of Warcraft profile and use its Open Folder or Browse Folder action. The correct AddOns folder is the one that already contains Offhand.

Using Battle.net

Select the WoW version you play, open the options beside Play, and show the installation in Explorer. Open the matching game-version folder, then Interface and AddOns.

Common version folders _retail_\Interface\AddOns _classic_\Interface\AddOns _classic_era_\Interface\AddOns

Check before extracting: Offhand and Offhand_UserMedia must be side by side inside the same AddOns folder, not nested inside one another. Your drive and parent folders may differ if WoW was installed in a custom location.

Update or remove

Close WoW before replacing Offhand_UserMedia. To remove it, disable the custom background and delete only that folder. Normal CurseForge updates leave this user-owned package alone.

Expected folder structure

Keep both addon folders side by side inside Interface/AddOns.

Interface/AddOns/
├── Offhand/
└── Offhand_UserMedia/
    ├── Offhand_UserMedia.toc
    ├── Background.lua
    ├── BackgroundRecipe.json
    ├── README.txt
    └── Textures/Background.tga
