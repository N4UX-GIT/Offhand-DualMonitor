What the Companion does

The Companion identifies the visible World of Warcraft window, changes its border and dimensions across displays selected by the user, and gives the addon exact display geometry. For WoW Forever it can also refresh Offhand's own recovery data after WoW closes.

It does not request administrator access, install a service or driver, inject code, read WoW memory, automate gameplay, collect telemetry, or download and execute code. Update checks occur only when the user clicks Check for Updates.

See the public security disclosure, privacy statement, and build history.

Manual Setup

The in-game addon can arrange its viewport and workspace after you resize the ordinary WoW window across both displays. This fallback requires no Companion download.

Before you begin

  • Install and enable Offhand through CurseForge.
  • Arrange the monitor rectangles in Windows Display Settings to match their physical alignment.
  • Manual spanning leaves the title bar visible and usually must be repeated after launching WoW.
  • WoW Forever may not preserve every panel position across a complete restart without the Companion recovery bridge.

Span the window

  1. Choose Options → Graphics → Display Mode → Windowed, not Windowed (Fullscreen).
  2. Restore WoW to a movable window and drag it onto the Mainhand display.
  3. Drag the window edges across the second display until WoW covers the intended area.
  4. Type /reload, then run /offhand wizard and complete the setup.

Forever and recovery

On WoW Forever, configure action bars and combat frames with Blizzard Edit Mode, save the layout as Offhand, and select it.

To return to one monitor, disable dual-monitor mode in /offhand, move WoW back to one display, and resize or maximize it normally. Use /offhand gather if an ordinary panel is inaccessible.
