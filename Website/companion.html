What the Companion does

The Companion identifies the visible World of Warcraft window, changes its border and dimensions across displays selected by the user, and gives the addon exact display geometry. The span remains in place if you then choose Exit Companion. Leave it in the tray only for optional automatic spanning, monitor-disconnect recovery, topology-file repair, or the Forever compatibility bridge.

It does not request administrator access, install a service or driver, inject code, read WoW memory, automate gameplay, collect telemetry, or download and execute code. Store installations use Microsoft Store for updates; portable installations contact GitHub only when the user clicks Check for Updates.

See the public security disclosure, source, and build history.

NO EXECUTABLE REQUIRED

Independent Setup

FancyZones and ordinary manual resizing both use Offhand's remembered-canvas workflow. Place WoW, confirm it visibly, and save the current canvas from the in-game guide.

Before you begin

  • Install and enable Offhand through CurseForge.
  • Arrange the monitor rectangles in Windows Display Settings to match their physical alignment.
  • FancyZones is the recommended Windows assistant. Manual placement remains supported everywhere.
  • An earlier Forever build needed a recovery bridge for an intermittent SavedVariables loading defect. Current builds are being revalidated with the Companion fully exited.

Place and remember the window

  1. Choose Options → Graphics → Display Mode → Windowed, not Windowed (Fullscreen).
  2. Snap WoW into a saved FancyZones Canvas zone, or drag and resize it over the intended area yourself.
  3. Run /offhand guide, choose the matching method, and select Remember Current Window only after visually confirming the placement.
  4. Complete calibration. On Forever and Retail, create the Mainhand HUD layout outside combat, then reload when prompted.

Forever and recovery

On WoW Forever, let the setup wizard create and select the initial Mainhand HUD layout. Use Blizzard Edit Mode only for personal fine-tuning; use Recovery & Preview to rebuild or designate it later.

To return to one monitor, disable dual-monitor mode in /offhand, move WoW back to one display, and resize or maximize it normally. Use /offhand gather if an ordinary panel is inaccessible.
