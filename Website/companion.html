What the Companion does

The Companion identifies the visible World of Warcraft window, changes its border and dimensions across displays selected by the user, and gives the addon exact display geometry. For WoW Forever it can also refresh Offhand's own recovery data after WoW closes.

It does not request administrator access, install a service or driver, inject code, read WoW memory, automate gameplay, collect telemetry, or download and execute code. Update checks occur only when the user clicks Check for Updates.

See the public security disclosure, privacy statement, and build history.
