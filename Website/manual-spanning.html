Manually span World of Warcraft

The in-game addon can arrange its viewport and workspace after you resize the ordinary WoW window across both displays. This fallback requires no Companion download.

Before you begin

  • Install and enable Offhand through CurseForge.
  • In Windows Display Settings, arrange the monitor rectangles to match their physical left/right and vertical alignment.
  • This method leaves the Windows title bar visible and usually must be repeated after launching WoW.
  • WoW Forever may not preserve every Offhand panel position across a complete client restart without the Companion recovery bridge.

Setup steps

  1. Open WoW and choose Options → Graphics → Display Mode → Windowed. Do not choose Windowed (Fullscreen).
  2. If the window is maximized, restore it to a movable window. Drag its title bar onto the monitor that will contain the game view.
  3. Drag the left or right window edge across the second monitor. Adjust the top, bottom, and outer edges until the WoW window covers the desired area of both displays.
  4. Return to WoW and type /reload so Offhand reads the final window dimensions.
  5. Type /offhand wizard and complete the setup. Choose which side is Mainhand and which side is the workspace.
  6. On WoW Forever, configure action bars and combat frames with Blizzard Edit Mode, save the layout as Offhand, and select it.

Returning to one monitor

Disable Offhand's dual-monitor mode in /offhand, then drag the WoW window back onto one display and resize or maximize it normally. If an ordinary panel is inaccessible, use /offhand gather.
