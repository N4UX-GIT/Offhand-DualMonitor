## [2.1.5-beta.29] - 2026-11-10

- Improved EllesmereUI and SexyMap compatibility so automatic window recovery
  respects their minimap placement.
- Improved EllesmereUI scaling when spanning and when returning to a normal window.
- Fixed open NPC windows becoming unreachable after disabling Offhand or restoring
  the window in Forever.
- Fixed Forever backpack behavior when closing Chat Settings, using the close
  button, or pressing Escape with a target selected.
- Improved placement compatibility with Details, BetterBags Next and RestedXP.
- Fixed spacing and scaling of remaining loot-roll windows after an earlier roll finishes.
- Improved oversized item-tooltip fitting and restoration.
- Added optional Mainhand centering for ProcDoc alerts while preserving its own offsets.
- Improved DaylightUI world-map compatibility, including restoring its placement
  and controls when Offhand releases the map.
- Fixed the Forever setup Reload UI button and improved setup guidance.

Existing settings and layouts are preserved. No Companion update is required.
