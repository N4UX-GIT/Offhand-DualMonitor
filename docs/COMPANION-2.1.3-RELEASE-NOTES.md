# Offhand Companion v2.1.3

Prepared release notes for the clean Companion version. The separately installed
Offhand add-on remains **2.1.3 Pre-Release Beta 27**, not a stable add-on release.

- Custom workspace plans, visual area selection, previews and named display-plan
  profiles, including single-monitor, partial-secondary and Flexible Layout options.
- Active Windows display-target identities, safer stale/missing monitor handling,
  Windows scaling and HDR/SDR diagnostics.
- Window recovery/Restore safeguards, fullscreen taskbar presentation and clearer
  setup, Help, editor and manual `/reload` guidance.

Microsoft Store remains the recommended Windows installation:
https://apps.microsoft.com/detail/9PL4PW84Q90W

Portable assets: `Offhand-Companion-v2.1.3.zip` and `Offhand.exe`.
Install the matching **2.1.3 Pre-Release Beta 27** add-on separately for the new
workspace integration. Run WoW in ordinary Windowed mode, review Mainhand and
Workspace layout, click Span WoW Now, then type `/reload` in WoW.

The portable EXE is unsigned. Verify the attached checksums and keep security
protections enabled. This exact sample has clean local Defender scans but no
Defender file-review determination. Store certification, portable signing and
SmartScreen reputation are separate. Previous Microsoft results concern other
hashes. See the source release records for the WACK results and acceptance limits.
