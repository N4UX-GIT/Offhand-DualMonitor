# Offhand Companion 2.1.8

- Workspace Profiles explains how to enable saving when the current layout is Standard. In Workspace layout, choose Multiple workspaces or Flexible and save the plan before creating a profile.
- If Windows cannot supply a stable identity for a selected display, Companion identifies the affected display and points to Copy Display Diagnostics.
- Copy Display Diagnostics retains the most recent span bounds failure from the current session. It shows the requested and observed WoW window bounds, the selected workspace bounds and the rollback result.

Existing preferences and workspace profiles carry forward. This update uses the same Companion protocol and works with Offhand Beta 32 and Beta 33.

Windows users can get the Companion through the Microsoft Store. For the portable edition, extract the ZIP and run `Offhand.exe`. Portable updates are manual. [Microsoft Store listing](https://apps.microsoft.com/detail/9PL4PW84Q90W)
