# Region sizing live QA on Forever

Target: Noggaholic, WoW Forever 1.60.1 build 70862, on the corrected Companion 2.1.6 candidate (`5BC115E2B16E1FD384836E96BC0E9E7C0F377D9A0DC825533169C427DA376919`). The addon remains the private 2.1.5 beta.28 subject with two recorded UI corrections. Its Settings header lists the addon manifest's Companion version, not the running Companion version. The running path, binary hash and accepted generated metadata establish the tested Companion identity.

- Split topology: Companion 2.1.6 wrote schema 1 with metadata v1 and 100% Windows scaling on both sides. Calibration opened at 100%. A 77% manual preview, chat preview, Discard, Auto preview, Settings opening and reload left region preferences empty and generated zero calls to the new scale writer. Five sampled native roots retained local scale 1.0. This is separate from the existing global UI scale changing with window geometry.
- Custom topology: used the real Companion editor to create a centered 1280×1440 game area with two 640×1440 workspaces on one display. The generated schema 3 bridge contains both region metadata records. WoW accepted both regions and defaulted to 100% before Apply. Workspace A at 75% left Workspace B at 100% until B was explicitly set to 125%. Both values were captured together; calibration showed A at 75% after a full client restart.
- UI defects found: the Settings card initially overlapped map controls; the scaled preview moved vertically; switching to Auto in calibration caused recursive reflow and a recorded stack overflow. The measured card height, unscaled preview anchor and guarded reflow fix these issues. The updated client displayed the card and the preview in their intended positions, and the Auto preview resized the wizard normally. The regression fixture covers the recursive parent callback with native height rounding.
- Replacement bags: EllesmereUIBags moved without a region scale change. Temporarily disabled the bag, QoL and Blizzard skin modules for native testing. The native backpack opens in Workspace A. A synthetic cross-region drag did not yield a verified destination change; do not count it as a pass. The map and quest pane extended across the seam in this narrow layout with and without those modules; map fit remains open.

## Combat follow-up on Forever 1.60.1 build 70888

Noggaholic used the accepted Companion 2.1.6 schema 3 topology with the newer Settings and Calibration controls overlaid on the addon. The original QA Prepare combat button set Workspace A to 75% and opened Calibration, then errored when it tried to click an inner control through the new advanced-options wrapper. The repaired probe prepares the baseline and lets the visible Calibration controls stage the preview.

The saved trace records two real combat intervals with Apply. Both queued a refresh with zero calls to the region scale writer during combat. The queue cleared by the sample 0.4 seconds after each `PLAYER_REGEN_ENABLED`. Workspace A resolved to 100% and Workspace B retained 125%. Both backpack roots were closed in those samples. The visible Combined Backpack later reported local scale 1.0, compared with 0.75 in the visible pre-test sample. The closed backpack prevents a conclusion about live resizing at combat exit.

The open-backpack follow-up passed on the same build and topology. The player applied an Auto 100% draft in Calibration during combat and reported that the backpack stayed open. The probe measured the visible Combined Backpack at local scale 0.75 before combat and 1.0 afterward. The Apply snapshot had a queued refresh. There were zero writes during combat and one write to the Combined Backpack at `PLAYER_REGEN_ENABLED`. The 0.4-second exit sample confirmed Auto resolved to 100%, the queue was clear and Workspace B was still 125%. The harness saved the trace to `combat-open-backpack.private.lua`, and `verify-combat-retry.lua` passed.
