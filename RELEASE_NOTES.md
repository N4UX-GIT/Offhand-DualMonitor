# Offhand Beta 43

Offhand `2.1.5-beta.43` is an addon-only update. It uses the existing Windows Companion `2.1.9-beta.4`.

## Addon

- Search the in-game Offhand settings and select a result to open its section.
- Scale the Character window down to 35% on Offhand.
- On Forever, opening the Game Menu with Escape keeps detached Mainhand chat visible.
- OpenMap camera follow on Offhand starts off. Enable it under **Offhand Monitor > World Map Scaling & Navigation**.
- Baganator's backpack keeps its Offhand bag-key and Escape protection during layout refreshes. Escape no longer uses stale state to reopen a closed backpack.

## Open reports on Forever

Intermittent phantom chat backgrounds, Baganator flicker or Escape lockout, and failures to open View Talents remain under investigation.

## Downloads

- The addon ZIP installs into `Interface/AddOns/Offhand`.
- For a new Companion installation, use the existing [Windows Companion 2.1.9-beta.4 release](https://github.com/N4UX-GIT/Offhand-DualMonitor/releases/tag/v2.1.9-beta.4).
